# Bússola — Site Institucional

Site institucional e de produto da Bússola, plataforma de gestão clínica para psicólogos autônomos.

## Sobre o produto

A Bússola integra agenda e financeiro para psicólogos com carteira recorrente. O foco é reduzir o tempo gasto em administração sem retirar do profissional o controle sobre seus dados e sua prática.

O produto está em desenvolvimento. Este site é a presença pública durante a fase de validação e lista de espera.

## Sobre este repositório

Site estático de página única (`index.html`). Todo o CSS e JavaScript estão inline. Fontes carregadas via Google Fonts (DM Serif Display + Inter).

Sem framework, sem build step, sem dependências. Para visualizar: abra o `index.html` no browser.

## Deploy

Hospedado na Vercel como site estático. Arraste o `index.html` no [vercel.com/new](https://vercel.com/new) ou conecte este repositório.
